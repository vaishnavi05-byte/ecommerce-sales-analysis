# Excel Dashboard

Interactive e-commerce sales and delivery dashboard built using Excel Power Query, PivotTables, PivotCharts and slicers.

The dashboard includes:
- Merchandise sales value
- Delivered orders
- Average order value
- Late-delivery rate
- Average delivery days

Customer-state and purchase-year slicers filter the metrics and charts.

Sales cover delivered orders, and merchandise value excludes freight. Delivery metrics use orders with valid delivery dates.
